# HISHAM

تطبيق Android عربي لتفريغ إشعارات الحوالات وإيداعات المحافظ الإلكترونية من الصور إلى كشف CSV منظم. التطبيق يعالج الصور محلياً، يصنف الإشعار، يستخرج رقم المرجع والمبلغ والعمولة واسم المودع، ويتيح مراجعة الحقول قبل التصدير والمشاركة.

## ما تم تنفيذه

تتضمن النسخة الأولية اختيار عدة صور، معالجة جماعية مع مؤشر تقدم، قواعد استخراج عربية، تصنيف «إيداع محفظة» أو «حوالة صرافة»، حالات «مراجعة يدوية» و«خطأ في القراءة»، شاشة تعديل للنتائج، وCSV بترميز UTF-8 BOM وفاصل `;`. زر المشاركة يفتح واجهة Android القياسية، ولذلك تظهر تطبيقات البريد وواتساب والبلوتوث عندما تكون مثبتة ومسموحاً بها على الجهاز.

زر «تجربة مثال» مخصص لمراجعة التدفق في المعاينة دون الحاجة إلى صورة. في معاينة الويب تُستخدم عينة محلية؛ هذا ليس ادعاءً بأن متصفح الويب يشغل OCR عربي دون اتصال.

## المعاينة والتحقق

```bash
pnpm install
pnpm check
pnpm exec vitest run
pnpm dev
```

تستخدم المعاينة الثابتة منفذ Metro `8081` وخادم القالب منفذ `3000`، كما هو محدد في مشروع Mobile. يمكن فتح Preview من لوحة Manus أو تشغيل Expo Web محلياً.

## Android وOCR العربي

طبقة Android تستخدم واجهة React Native الحالية فقط لاستدعاء **Tesseract4Android 4.9.0** الحديث، بعد استبدال محرك `com.rmtheis:tess-two` القديم، مع ملف `assets/tessdata/ara.traineddata`. الإضافة `plugins/with-tesseract-assets.js` تنسخ النموذج إلى `android/app/src/main/assets/tessdata` أثناء Expo prebuild، ولذلك يجب استخدام Android build حقيقي أو Custom Development Client. لن يعمل OCR الأصلي داخل Expo Go العادي.

طبقة الجسر نفسها ستبقى صغيرة فقط لتوصيل React Native بالمحرك، لكن محرك OCR لم يعد `tess-two` القديم. يجب عدم تقديم APK للمستخدم قبل تجربة صورتين عربيتين حقيقيتين على هاتفه.

لبناء APK/AAB، استخدم إجراء Android build من Dashboard/EAS بعد قبول checkpoint المشروع. لا يتم ادعاء وجود APK جاهز من هذه المعاينة وحدها؛ نجاح web preview وTypeScript لا يثبت نجاح native OCR.

## تنسيق CSV

رؤوس الملف هي: `رقم المرجع;نوع الإشعار;المبلغ;العمولة;اسم المودع;البيان المحاسبي`. يتم وضع BOM في أول الملف، وتُقتبس القيم التي تحتوي على فاصلة منقوطة أو سطر جديد حتى لا تتداخل الأعمدة في Excel.

## مصدر OCR المفتوح

يستخدم المشروع واجهة **react-native-tesseract-ocr** مع محرك **Tesseract4Android** الحديث: <https://github.com/adaptech-cz/Tesseract4Android>. نموذج العربية مأخوذ من مستودع Tesseract الرسمي: <https://github.com/tesseract-ocr/tessdata_fast>. إذا حفظ Samsung Internet رابط APK باسم `.bin` فهذا خلل MIME في التنزيل، وليس ارتباطاً بتطبيق Samsung Health؛ افتح الرابط في Chrome أو أعد تسمية الملف إلى `.apk` قبل التثبيت.
